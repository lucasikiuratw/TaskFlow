TaskFlow — Gerenciador de Tarefas

Sobre o projeto
O TaskFlow é uma aplicação web desenvolvida para auxiliar na organização e no gerenciamento de tarefas diárias.

O sistema permite cadastrar tarefas, visualizar atividades pendentes, marcar tarefas como concluídas e excluir registros.

Objetivo
Desenvolver uma aplicação simples utilizando conceitos básicos de programação, desenvolvimento web e banco de dados.

Tecnologias utilizadas
- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLite

Funcionalidades
- Cadastro de tarefas.
- Listagem de tarefas.
- Conclusão de tarefas.
- Exclusão de tarefas.
- Indicadores de produtividade.
- Gráfico de tarefas concluídas e pendentes.

Como executar
1. Instalar Python.
2. Instalar as dependências com `pip install -r requirements.txt`.
3. Executar `python app.py`.
4. Abrir `http://127.0.0.1:5000` no navegador.
